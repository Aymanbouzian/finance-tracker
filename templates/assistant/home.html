Connect local AI

On the computer running PocketLedger, install Ollama, then download the model:

ollama pull qwen3:4b

Enable OLLAMA_ENABLED=1 in the app's server environment and restart it. The local default is http://127.0.0.1:11434.

On your phone, the model runs on your app server. Keep that server reachable. See docs/LOCAL_AI.md for Docker setup and model choices.
