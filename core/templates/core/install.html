Install on this device

Use the button when your browser offers installation, or follow the steps below.

Install PocketLedger

Android

Open this app in Chrome. Open the browser menu, choose Install app or Add to Home screen, then confirm.

iPhone & iPad

Open this app in Safari. Tap Share, choose Add to Home Screen, and tap Add.

Desktop

In Chrome or Edge, use the install icon in the address bar or the browser menu. In Safari on supported Macs, choose File → Add to Dock.

Your devices, connected to your server

Open the same server address and sign in with the same account on each device to access your records. Your server must be running and reachable.

Installation needs HTTPS, or localhost on the device running the server. This version needs a connection to view and save financial records. If the connection drops, the app shows a reconnect screen; it does not save records offline.
